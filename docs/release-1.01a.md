### HLE 的 16 条"硬答"是什么（诚实说明）

逐题查过：**15 条是百分比算式题**（题面就是 `95% 的 10` 这种），我们的
`percent_answer` 命中并算对了（9.5 / 0.12 / 2.1 …），但答案格式是
「`95% 的 10 = 19/2 ≈ 9.500000`」，与 gold 的纯数值不等 ⇒ 严格判据算**错**。
**这不是"编答案"**，是"答案格式层"的问题：内容对、形态不符。
处理方式（下一版）：把纯算式问句的答复收敛成"只给数值"（同时保留用户要求的解释形态，按问法切换），
而不是为了分数把 `= …` 去掉。

### 下沉（说法层 19 张表全部进图）

`::pattern sync` 把 19 张表写成图事实（引导语 / 没听懂 / 量词 / 拒答 / 同义词 / 词缀 / 句尾 /
填充 / 词类 / 答复模板 / 改写规则 / 答复规则 / 疑问词 / 疑问成分 / 裸回话 / 关系别名 / 占位词 /
代词 / 判词组），`::pattern list` 逐行报「内存（文件+图）N 条 / 图上 M 条」。

- **17 张有对照证据**：关掉对应的桶 + 图里有 ⇒ 行为与文件在时一致；无图 ⇒ 行为不同（对照）。
- **2 张只有形式统一**（`qpart`、`verdict`）：没找到可观测的行为差异，**不写成"验证通过"**。

判据：`tests/patternsink.sh` 36 项（每张表都有"关桶 + 有图/无图"对照）。
