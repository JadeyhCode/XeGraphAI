# 蒸馏「骨架 + 知识」：教师只给语言变体，真假由学生裁决

> 一句话：**0.6B 当不了数据工厂，但能当词表工厂。** 让它生成"说法变体"（骨架），
> AI 用已有的 `[lead]`/`[tail]` 数据行学；它提议的"知识"一律进待证门 —— 门是确定性的。

## 0. 先记上一次怎么错的（这轮返工的原因）

第一版让 0.6B 直接产出「骨架 + 知识」，结果（原始输出在 `distill/raw_facts.txt`）：

```
猫 属于 猫        火 属于 火        书 属于 书      ← 23 行全是**自环**
[问] <X> 音乐                      ← "骨架"根本不是问句
[答] <X> 喜欢 <X>
```

我的门只查了"重复主语"，没查 `s == o`；骨架的判据是"答复里有没有主题词"，
于是 `[问] <X> 音乐` 也能过，还报出「骨架 2/10 → 8/10」——**那是假分**。
结论：**教师不该提供事实和结构**；它提供这两样时，错误是系统性的（0.6B 只是把词表
按模板重排），任何"看起来像"的弱门都拦不住。

## 1. 改后的分工

| 角色 | 谁干 | 判据 |
|---|---|---|
| **骨架**（问法的包装） | 教师只列**礼貌前缀/句尾**（劳驾、麻烦问一下、多谢…） | 学生：包装前答不出、包装后答得出、**没教过的问句**套同一包装也答得出 |
| **知识**（事实） | 教师只**提议**三元组 | 确定性门：词池 / 关系表 / 自环 / 重复 / 分类冲突 ⇒ 过了也只进 `distill/claims.txt`（**待证**），要 `::claim accept` 才算数 |
| 学习机制 | 仓库原有：`[lead]`/`[tail]` 是一行一条的数据 | 不新增 C 路径 |

关键点：**教师的产物不需要"被相信"**。包装前后的答复是否一致，是可计算的；
事实能不能进图，由门和用户决定。

## 2. 实测（`python3 tools/distill_wrappers.py --teacher …`）

教师 `qwen3-0.6b`（18321）产出：

```
[lead] 劳驾 请问 麻烦问一下 想请教 打扰一下      （5 个）
[tail] 谢谢 多谢 拜托了 不胜感激                 （4 个）
```

学进 `patterns.txt` 之后（`tests/distilllearn.sh`，同二进制同模型，只有数据不同）：

```
[基线] 前缀+问句 答得出：8/20（缺口 12）
[学后] 前缀+问句 答得出：20/20
[举一反三] 教过的前缀 + **没教过**的问句：20/20
```

`8/20 → 20/20`：增量全部来自教师给的说法；`20/20` 里有一半是**没教过的问句**
（`猫 有 毛 吗` / `鸟 会 飞 吗` …）—— 这才叫举一反三：学的是**前缀**，不是某句话。

## 3. 知识：0.6B 的提议被门全部拦下（负结果，照记）

```
[知识] 过门后 0 条（自环/重复/池外/分类冲突都挡了）
```

23 行提议 → 23 行自环 → 0 条。**这不是失败，是门在工作**：宁可一条不进，
也不让 `水 属于 水` 这种边进事实层。要用小模型蒸馏事实，得换一条路：
  ① 教师换强的（`--teacher` 指过去即可）；
  ② 或者让用户的确认当裁判（`::claim accept`，仓库已有）；
  ③ 或者只蒸馏"教师能自我验证"的东西（例如把事实改写成问句，学生答对才算）。

## 3b. 换 3B 教师：格式对了，真假还是不能信；但**待证回路**能收

同一个脚本换 `qwen2.5-coder-3b`：

```
[lead] 劳驾 请问 麻烦问一下 想请教 打扰一下 请问一下 麻烦一下 想请教一下   （8 个）
[知识] 过门后 3 条：游泳 属于 运动 / 唱歌 属于 音乐 / 做饭 属于 食物
[基线] 12/32 → 学后 32/32，留出 32/32
```

事实的质量：`游泳 属于 运动`✓、`唱歌 属于 音乐`✓、`做饭 属于 食物`✗ —— **2/3**。
比 0.6B（23 行全自环）好，但**仍然不能直接进事实层**。所以它进的是待证：

```sh
::claim ingest distill/claims.txt     # 收进待证：来源「教师」，可信度 40/100
::claim                                # 列出来（**都不算数**）
::claim accept 1                       # 你确认 ⇒ 才升成事实（记成「是你教的」）
游泳 属于 运动 吗                      # ⇒ 对 ， 游泳 -[属于]-> 运动
```

这一段也钉进了 `tests/distilllearn.sh`（5 项）：收进 3 条 / 来源标「教师」/ 确认前**不进事实层** /
确认后升成事实 / 升完答「对」。**真假由用户的确认裁决**，不由教师。

## 4. 文件

| 文件 | 作用 |
|---|---|
| `tools/distill_wrappers.py` | 生成说法变体 + 提议事实；机械门；沙箱前后对比 |
| `tests/distilllearn.sh` | 判据（不联网、确定性）：基线/学后/留出三条同时成立 |
| `tests/fixtures/distill/wrappers.txt` | 教师产出的说法（一行一条，进 `patterns.txt`） |
| `distill/claims.txt` | 教师提议的事实（**待证**，不进事实层） |
| `distill/raw_facts.txt` / `raw_wrappers.txt` | 原始输出（复查用，不进 git） |

## 5. 局限

1. 说法变体只能补**包装**这一层；内容型变换（同义谓语/句法/多级分类）还得靠别的机制
   （见 `docs/capability-map.md` 第 2 节）。
2. 0.6B 的说法质量也有限：这轮 9 个里 4 个是"请问/谢谢"这类常见词（本来就认识），
   真正新增的是"劳驾/想请教/打扰一下/拜托了/不胜感激"。
3. 知识蒸馏在这条路上**没有产出**（0 条）。下一步要么换大教师，要么走 `::claim` 确认流。
