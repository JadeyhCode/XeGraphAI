# JainkAI Flash 版（v1.01a-flash）

**一句话**：同一份知识、**体积 1/5** 的轻量模型 —— 只保留"在测试负载里真正被读过"的边；
**关系问答、算术、单位、日期、说法层全部不变**，代价是**自由联想变浅**。

## 数字（实测，可复现）

| 指标 | 主模型 `model.bin` | Flash `model_flash.bin` |
|---|---|---|
| 文件大小 | 2,903,008 字节（2.77 MB） | **584,476 字节（571 KB）**，≈ **1/5** |
| 边（文件里 / 装载后） | 41,198 / 41,198 | **1,142 / 1,158**（+16 来自 `relations.txt` 种子） |
| 关系边 | 238（读过 237） | 238（读过 237，全保留） |
| 共现/回复边 | 40,960 | ~900 |
| 能力电池（70 条） | 67/70（95.7%） | **67/70（95.7%）** |
| 关系问答（19 条对照） | — | **逐字相同** |
| 自由联想（40 种子） | 40/40，平均 **5.4 步**，不同词 108 | 40/40，平均 **2.0 步**，不同词 73（31/40 条产物不同） |

## 怎么构建（确定性，不靠手工）

```sh
sh tools/build_flash.sh            # model.bin → model_flash.bin
```

内部与 `tools/edge_prune.sh` 同一条流水线：
**每题一个进程**跑 348 句负载（每条关系边问一遍 + 电池纯问句 + 15 条开放问句）→ `::edges dump` 位图 →
干净模型 `::edges hitload`（并集）→ `::edges prune --yes --plain` 另存 → 跑电池验收。

## 怎么用

```sh
./build_aip --model model_flash.bin
```

## 代价说清楚（别踩）

1. **自由联想变浅**：联想走的是**共现/回复边**（`ai_pick_next_topic` 只收 `NONE`/`REPLY` 角色），
   而 flash 只保留"测试负载里被选中过"的共现边 ⇒ 多数种子的游走第一跳就没了候选，
   路径从平均 5.4 步掉到 2.0 步（40 个种子里多数是 1 步）。**想保留联想就别用 flash**。
2. **不是"删掉了没用的知识"**：删的是"这套负载没采样到的边"。换一套负载，保留下来的边会不一样；
   要更保守的版本，把负载扩大（更多开放问句/更多种子）再构建。
3. `relations.txt` 仍然会在装载时补 16 条种子边 —— flash 不改变"种子文件"这条通路。
4. 关系问答/算术/单位/日期/说法层不受影响（上面 19 条对照 + 电池 70 条都验过）。

## 什么时候该用它

- 需要**小体积**分发（手机/嵌入式/演示），且**不需要自由联想**；
- 作为"知识骨架"的参考：1,142 条边就能撑住 67/70 的电池与全部关系问答。
