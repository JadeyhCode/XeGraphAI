## 设计（v1，推荐先做 A 档）

**通用机制**（C 里只有这三件事，**没有** `if (strcmp(dev,"夸张"))`）：
1. **学**：说法式 / 定义式（见下）→ 建 `[手法:名字]`、例子、可选解释；
2. **认**：输入的分词序列与已学例子/骨架/标志词比对；
3. **命中**：不写关系事实，用 `[say] 手法.*` 的数据措辞说一句；教过解释就用解释（B 档）。

**数据形状**（全是现有 token/边，不改存档格式）：
```
[手法:夸张] --[例子]--> [手法例:我 饿 得 能 吃 下 一 头 牛]     ← 归一化词串（v1 精确比）
[手法例:我 饿 得 能 吃 下 一 头 牛] --[解释]--> [解释:很 饿]   （B 档；挂在**例子**上）
手法库 --[有]--> [手法:夸张]                                  ← 列得出来、存盘还在
```
（v2 例子可改存 `[手法例:$1 饿 得 能 吃 下 $2]` 的骨架，复用 `[shape]` 匹配。）

**现场学入口**（先做两个；都只认明确说法，不猜）：
- **说法式**（推荐主入口）：先说自己那句，再说 `这 是 夸张 说法` / `这 句 是 夸张 说法`
  ⇒ 取上一句原文当例子，记 `[手法:夸张]`；
- **裸形式**：`这 是 夸张` **只在 `[手法:夸张]` 已登记时生效**（否则会抢走
  `这 是 猫` 这种普通陈述——"夸张"第一次出现必须带 `说法/手法` 标记）；
- **定义式**：`夸张 是 一 种 手法` ⇒ 只登记 `[手法:夸张]`（还没有例子，先只认标志词）。

**命中后的说法**（数据行，加到 `patterns.txt` 的 `[say]` 段）：
```
[say] 手法.没有解释=这 是 $1 说法 —— 我 不 按 字面 记；你 想 让 我 记 住 什么，直 说。
[say] 手法.有解释=这 是 $1 说法，意思 是 $2（不 按 字面 记）。
```
（设备名/措辞都不在 C 里。）

## 判据（照第 3 步的形状）

1. 教 `我 饿 得 能 吃 下 一 头 牛` + `这 是 夸张 说法` ⇒ 图里有 `[手法:夸张]` 和例子；

2. 同一句再说 ⇒ 回「这 是 夸张 说法…」，**不再**出现「记下 了」；再问 `这 句 是 事实 吗`
   不把它当事实。

  但重复的夸张句不加强共现也更干净；若实测发现"这话我听过"的记忆掉了，再改成只挡关系。
