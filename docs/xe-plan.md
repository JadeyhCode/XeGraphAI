## 第 2 轮（需求 3：图补丁）

- `xe_patch.h`：补丁 = **边的增删列表** + 会话名 + 初始图指纹。
  - `xe_patch_record_edge`：改图的同时记一条补丁（+ / -）。
  - `xe_patch_save/load`：文本格式，`+ 主语<TAB>关系<TAB>宾语`。
  - `xe_patch_apply`：先验指纹（不符拒绝，`force` 可强放），再逐条重放。
- 自测 `tools/xe_patchtest.c`（15 项）：50 节点图上改 3 条 → 补丁 **141 B**；
  2000 节点图同样 3 条 → **145 B**（只差指纹位数），重放后增删都对、未碰的边还在。
- `tests/xe.sh` 同时跑两个自测，已挂进 `tests/suites.txt`。

## 第 3 轮（需求 4：会话隔离的记忆）

- `xe_session.h`：`自由图:<sid>` 当锚点，记忆挂锚点边；磁盘每会话一个
  `_sessions/<sid>.patch`（复用补丁格式），外加 `_sessions/_base.fp` 记初始图指纹。
  - `xe_sess_remember / xe_sess_recall / xe_sess_forget / xe_sess_load`。
- 自测 `tools/xe_sesstest.c`（23 项）：s1 记 3 条、s2 记 1 条，互相看不到；
  重开进程装载后记忆都在（s1=131 B、s2=82 B）；忘掉一条后重载仍是忘掉的。
- 踩坑：校验补丁时拿「活图指纹」比会失败——装过 s1 之后活图多了 `自由图:*` 的边；
  正确语义是比 `_base.fp`（补丁是给哪张**初始图**打的），不是比当前内存图。
- `tests/xe.sh` 现在三件套串跑。

## 第 4 轮（需求 5：插件）

- `xe_plugin.h`：插件 = `name` + `hint` + 自己的 `assoc()`（联想规则）+ 自己的 `act()`（行为）。
  - `xe_plug_bind`：在图里建 `插件:<名>`，挂 `行为:<名>` 与 `词:<hint>` 两条边。
  - `xe_plug_dispatch`：**先联想、再行为**；认不了返回 0，不劫持别的输入。
- 自测 `tools/xe_plugintest.c`（10 项）：回声插件（只有行为）与计算器插件
  （联想把“加/减”翻成 `+/-`、行为再算）都通；`算 3 加 4 → 7`；
  `今天天气不错` 与 `复读`（缺参数）都交回主流程。
- 踩坑：行为里又调了一次联想规则，输入已被翻译过 ⇒ 二次翻译失败；
  派发的正确语义是「联想一次、行为只认插件自己的语言」。

## 第 5 轮（需求 6：现场学习）

- `xe_learn.h`：
  - `xe_learn_text/line`：从文本里抽 `X 是 Y` / `X 属于 Y` / `X 也叫 Y` / `X 需要 Y`；
    学到的不是字符串对，而是 **词→空→义**（多义多空）或 **空→关系→空**；
  - `xe_learn_html`：先剥标签、解 `&amp; &lt; &gt; &quot;`，再按行学（对应“抓网页后学习”）；
  - 每条学习都**同时记进补丁**，且只记图里真实存在的边（否则重放会丢空层）。
- 自测 `tools/xe_learntest.c`（14 项）：4 行小抄学会 4 条、认不出的行跳过、
  `递归 需要 栈` 落成 空→空、补丁 7 条增量/290 B、另一进程重放后仍能查到；
  HTML 里学 2 条（script 内容不算）。
- 踩坑：补丁一开始记的是 `词 --义--> 义`（图里没这条边），重放后空层丢了、
  `has_sense` 失败；改成记录真实的两跳边就对了。
- 联网抓取仍走原有 `::web`（离线环境下只测“抓回来之后的处理”）。

## 第 6 轮（需求 7：元认知承接奖励 + 辅助泛化）

- `xe_meta.h`：
  - `xe_meta_reward(err, cons, nov)`：奖励 = `1 - w_err*err + w_cons*cons + w_nov*nov`，
    不再查写死的奖励表；三个权重由 `xe_meta_feedback` 按反馈学（正反馈把对的特征权重推高）。
  - `xe_meta_accept`：接受线 = 奖励运行均值 + k*标准差（**随经验漂移**，不是固定阈值）。
  - `xe_meta_generalize`：把关系沿“属于”继承给新词（写 空→空），
    支持度要跟自己**采纳过的泛化**比；没历史时先采纳一次。
- 自测 `tools/xe_metatest.c`（13 项）：好样本 1.00 / 坏样本 0.60；正反馈把 w_err 从 0.50 推到 0.72；
  高分基线线 1.02 对 0.60 判拒、低分基线线 0.56 判收；采纳的边真写进图，拒绝时图没被改。


## 第 4 轮（设计澄清：空符号是匿名占位，信息在图里）

用户澄清：**空符号本身不携带信息，它在图中的位置决定信息**
（所以不能把词/义写进空符号的名字里）。

- 改法：`xe_hole_new` 生成 `空#n`（唯一编号，无语义）；`xe_hole` 按「是否已有
  `--义--> 义:<sense>` 的空」复用（幂等）；`xe_hole_n` 按**建边顺序**取第 n 个；
  学习写补丁时记空符号**真实名字**，重放可复原。
- 自测新增：“空符号名字不带语义（空#n）”；`sh tests/xe.sh` 六件全过。
