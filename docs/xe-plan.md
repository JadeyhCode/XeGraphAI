## 第 2 轮（需求 3：图补丁）

- `xe_patch.h`：补丁 = **边的增删列表** + 会话名 + 初始图指纹。
  - `xe_patch_record_edge`：改图的同时记一条补丁（+ / -）。
  - `xe_patch_save/load`：文本格式，`+ 主语<TAB>关系<TAB>宾语`。
  - `xe_patch_apply`：先验指纹（不符拒绝，`force` 可强放），再逐条重放。
- 自测 `tools/xe_patchtest.c`（15 项）：50 节点图上改 3 条 → 补丁 **141 B**；
  2000 节点图同样 3 条 → **145 B**（只差指纹位数），重放后增删都对、未碰的边还在。
- `tests/xe.sh` 同时跑两个自测，已挂进 `tests/suites.txt`。
