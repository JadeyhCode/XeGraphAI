## 设计（v1）

格式定义（数据）：

`[say] 格式.列表=- $A`
`[say] 格式.表格=| 回答 |\n|---|\n| $A |`
`[say] 格式.JSON={"answer":"$J"}`

- `$A` = 最终答复原文；`$J` = 同一段话的 JSON 字符串转义版；
  `\n` / `\t` / `\\` 在填充时还原，其它字符原样。
- 自定义格式：`格式库 --[有]--> [格式:自定义1] --[模板]--> [模板:结论：$A\n下一步：无]`；
  图里的优先于 `[say]`。

会话态（不存盘）：

`char fmt_active[40]` / `char fmt_once[40]` / `size_t fmt_out_cap` / `uint8_t fmt_suppress`。

入口语法（只认明确形式）：

- 一次性：`用 <名> 回答：<问题>` / `按 <名> 格式 回答：<问题>`；`<名>` 必须在数据里有，
  否则不抢，交回流水线。
- 持久：`以后 用 <名> 回答` / `以后 按 <名> 格式 回答`（只激活）。
- 教模板：`以后 按 这个 格式 回答：<模板>`（自动命名 `自定义N`，存图并激活）。
- 取消：`正常回答` / `不用格式`。
- 含 什么/哪/怎么/如何 的名字不抢。

渲染点：`agent_say` 里若 `fmt_once`/`fmt_active` 有值且答复非空/非"……"，用
`ai->fmt_out_cap` 作上限填模板；`fmt_once` 答完即清；`fmt_suppress` 的确认答复跳过。

## 判据（v1）

1. `用 列表 回答：猫 属于 动物 吗` ⇒ 以 `- ` 开头且含 `对`；下一句不套格式。
2. 表格含 `| 回答 |`；JSON 以 `{"answer":"` 开头、`"}` 结尾。
3. `以后 用 列表 回答` ⇒ 之后每条以 `- ` 开头；`正常回答` 后恢复。
4. `以后 按 这个 格式 回答：…` ⇒ `::edges 格式库` 见 `[格式:自定义1]`；随后回答含
   `结论：` / `下一步：无`；存读后还能 `以后 用 自定义1 回答`。
5. 普通陈述/疑问零误伤；未知格式名（一次性）不抢；`AIP_NODATA=1` 不崩。
6. 109/109 通过。

## 不做 / 边界

- 不改存档格式；格式定义用现有 token/边，active/once 只进内存。
- C 里不出现"列表/表格/JSON"的专门分支；它们只是 `[say] 格式.*` 数据。
- v1 的表格是一行（`$A` 整句）；真正的"主语/关系/宾语"列留 F3。
- 不把随便一句 `用…回答` 都当格式请求：一次性名字必须在数据里；`以后…` 的明确教学
  才回"没有这个格式"。
