# 插件文档（`xe_plugin.h`）

> 版本：V0.08a（2026-11-14）。插件 = 挂到图上的**扩展符号**：自带联想规则和/或行为。
> 核心纪律：**插件不许劫持不认识的输入**（不认就返回 0，交回主流程）。

## 一、能做什么 / 不该做什么

| 能做 | 不该做 |
|---|---|
| 自己的**联想规则**（把输入翻译成插件自己的语言）| 联网、起子进程、写文件 |
| 自己的**行为**（纯函数式计算一个答复）| 劫持不认识的输入（必须返回 0）|
| 在图上登记 `插件:<名>` 与 `行为:<名>` 两条边 | 直接改别的插件/核心的边 |

## 二、数据结构

```c
typedef struct XePlugin {
    const char *name;   /* 插件名（图里 插件:<name>）*/
    const char *hint;   /* 输入里出现这个词就轮到它；空 = 不由 hint 触发 */
    int (*assoc)(XePlugin *p, const char *in, char *out, size_t cap); /* 可空 */
    int (*act)(AI *ai, XePlugin *p, const char *in, char *out, size_t cap); /* 可空 */
} XePlugin;
```

约定：`assoc/act` 返回 **1 = 我认了并给出答复**，**0 = 我不认，交回主流程**。

## 三、注册与绑定

```c
XePluginReg reg;
xe_plug_reg_init(&reg);
xe_plug_register(&reg, &my_plugin);   /* 注册（进程内）*/
xe_plug_bind(ai, &my_plugin);         /* 挂到图上：插件:x --行为--> 行为:x；有 hint 再加 -联想-> 词:hint */
```

派发（主流程里调）：

```c
char out[512];
if (xe_plug_dispatch(ai, &reg, user_input, out, sizeof out) == 1) {
    /* out 是插件的答复 */
} else {
    /* 没插件认 ⇒ 走原来的流程 */
}
```

派发顺序（`xe_plug_dispatch` 内部，固定）：

1. 按 `hint` 找插件（输入里包含 hint）；
2. 先调 `assoc` 把输入翻译成插件语言（返回 1 且有输出才采用）；
3. 再调 `act` 算答复；
4. `act` 不认但有翻译结果 ⇒ 翻译结果本身当答复；
5. 都不认 ⇒ 返回 0（主流程接手）。

## 四、完整例子（计算器插件）

```c
/* 联想：把「加 / 减」换成 + / - */
static int calc_assoc(XePlugin *p, const char *in, char *out, size_t cap) {
    (void)p;
    if (!strstr(in, "加") && !strstr(in, "减")) return 0;
    size_t o = 0;
    for (size_t i = 0; in[i] && o + 4 < cap; ++i) {
        if (!strncmp(in + i, "加", 3)) { out[o++] = '+'; i += 2; }
        else if (!strncmp(in + i, "减", 3)) { out[o++] = '-'; i += 2; }
        else out[o++] = in[i];
    }
    out[o] = 0;
    return 1;
}

/* 行为：只认自己语言里的 + / - */
static int calc_act(AI *ai, XePlugin *p, const char *in, char *out, size_t cap) {
    (void)ai; (void)p;
    long a = 0, b = 0; char op = 0;
    if (sscanf(in, "算 %ld %c %ld", &a, &op, &b) != 3) return 0;  /* 不认 ⇒ 交回 */
    snprintf(out, cap, "%ld", op == '+' ? a + b : a - b);
    return 1;
}

static XePlugin calc = { "计算器", "算", calc_assoc, calc_act };
```

自带自测（`tools/xe_plugintest.c`）覆盖：回声插件、计算器插件（走自己的联想规则）、
**不认识的输入不劫持**、**认了但答不了也交回主流程**：

```
gcc -std=c11 -O2 -I. -o build_xe_plugintest tools/xe_plugintest.c -lm
./build_xe_plugintest      # ALL OK
```

## 五、编写检查清单

- [ ] `name` 非空且唯一（图里是 `插件:<name>`）；
- [ ] `hint` 足够具体，避免和核心词冲突（冲突时核心优先，插件不该抢）；
- [ ] `assoc/act` 纯函数：不联网、不起进程、不写文件；
- [ ] 不认识的输入一律 `return 0`（不劫持）；
- [ ] 输出一定以 `\0` 结尾（`snprintf` 就够）；
- [ ] 有自测：认的输入、不认的输入、边界（空串/超长）各一条；
- [ ] 需要持久化的事实走 `::teach`/`::ingest`，不要塞进插件。

## 六、边界（照实说）

- 插件是**进程内**注册的：`xe_plug_register` 不落盘，进程重启要重新注册；
- 插件在图上只有两条边（行为/联想），**不参与推理**，也不进事实层；
- 插件失败必须自己返回 0，核心不会替它兜底。
