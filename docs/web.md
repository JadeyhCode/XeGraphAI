# 网页搜索：`::web` —— 只给线索，一律待证

> 一句话：**搜索不是知识**。抓回来的是标题/链接/摘要，标"待证"，要信就先 `::claim`。

## 怎么用

```sh
::net on                     # 联网这道门还是 net.h 那道（默认关 + 白名单 + 只认 https）
::web search 猫               # cn.bing.com 搜 ≤5 条：标题 / 链接 / 摘要
::web parse 某结果页.html     # 离线解析（不联网；套件就靠它判解析器）
```

实测（2026-11-09，本机）：

```
[网页搜索] 「猫」 5 条（来源 cn.bing.com；**待证**：不是我的知识，要信先 ::claim）
  1. 猫（猫科猫属动物）_百度百科
     https://baike.baidu.com/item/%E7%8C%AB/22261
     2023年10月25日·猫具有19对染色体，寿命有12-17年……
```

## 边界（和 `net.h` 的纪律一致）

| 条 | 内容 |
|---|---|
| 默认关 | `::net on` 才出去；`::web search` 在关着时直接拒绝（套件钉住） |
| 白名单 | `net/allow.txt` 精确匹配主机；现在只有 `cn.bing.com` 这条搜索入口 |
| 只认 https / 不跟重定向 / 不碰 Cookie | 复用 `net_fetch`，不是另开一道门 |
| 上限 | 每次 ≤ 2 MB / ≤ 15 s / 每次会话 ≤ 8 次（net.h 的硬上限） |
| 只抽三样 | 标题 / 链接 / 摘要；**不做正文抽取**（`net.h` 明确不做的那件事不在这里偷偷做） |
| 一律待证 | 不进事实层、不进说法层；`::claim` 确认才算数 |
| 抽不到就说 | "抓到了 N 字节，但一条结果也没抽出来"（页面结构变了就照实说） |

## 解析器怎么判（不靠网络）

套件 `tests/web.sh`（9 项）用**罐头 HTML**（`tests/fixtures/web/bing_sample.html`）判：
条数、标题、链接、摘要、`&amp;` 实体解码、标签不漏、空页面要照实说、联网关着要拒绝。
联网那条路只做**手工**验证（记录在本页），不进套件 —— 网络会抖，抖出来的红不是回归。

## 已知脆弱点

1. **依赖 cn.bing.com 的页面结构**：Bing 改版就得改 `web_parse_bing` 的选择器；
   抽不到时它会说"没抽出来"，不会编。
2. **链接可能是站的跳转链**（Bing 有时包一层），拿去用之前自己判断。
3. 摘要里的日期/省略号来自页面本身，不是我们的判断。
