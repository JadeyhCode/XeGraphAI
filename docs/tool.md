# 外部工具：`::tool` —— 拿本地大模型当工具，不当脑子

> 一句话：这个内核**不生成文本**，所以"不会答"是常态。`::tool` 让它把本地部署的
> 大模型当**工具**：问回来的是**它说的**，不是**我说的** —— 显示、记账、**不进图**。

## 怎么用

```sh
# 配端点（OpenAI 兼容；本机千问在 18321-18325，见桌面《本地模型-API凭据.txt》）
::tool set http://127.0.0.1:18321/v1 sk-local-... qwen3-0.6b
::tool on
::tool ask 中国的首都是哪里
#   [外部工具 qwen3-0.6b] 答（361 ms，**不是我的知识**）：
#   中国的首都是**北京**。
::tool log          # 时间 / 模型 / 问题 / 字节 / 成败
::tool off
```

实测（真端点）：`361 ms` 拿到答复；答复里带 **`不是我的知识`**，且 `::rel` 查不到它
（`答复没进图`）—— 这两条都是 `tests/tool.sh` 钉住的（8 项）。

## 纪律（和 `::net` 同一个形状）

| 条 | 内容 | 为什么 |
|---|---|---|
| 默认关 | 不开 `::tool on` 就一次请求都不发 | 和 `::net`/`::act` 一条线：往外走要显式 |
| 不用 shell | `fork` + `execv` + argv 数组 | 问题里的 `;` `|` `$()` 只是普通字符 |
| 硬上限 | 60 s / 回包 ≤ 1 MB / 到点 SIGKILL | 工具卡住不能把主进程拖住 |
| 只显示不吸收 | 答复**不进关系层、不进说法层** | 工具的话没有经过验证，不能变成"我的知识" |
| 失败照实说 | `没答上来：HTTP 500…`（带回包前缀） | 不编、不重试 |
| 记账 | 每次一行到 `tool.log` | "我问过谁、它说了什么"的唯一凭据 |

## 踩过的坑（写下来防再犯）

`curl` 的 `--data-binary` 要 **`@文件`**。漏了 `@`，curl 就把**路径字符串**当请求体发出去，
服务端只回 `parse error at line 1, column 1` —— 本地看代码完全看不出来。
现在 `tests/tool.sh` ③ 会检查落盘的请求体是不是以 `{` 开头。

## 它能干什么、不能干什么

- **能**：把"图里没有、但用户想知道的"转给本地模型，答案带出处；离线时可关。
- **不能**：让答案回灌成知识。想回灌就得走验证：`待证`（`::claim`）+ 用户确认，
  或者像 `docs/distill.md` 那样让确定性判据裁决。
