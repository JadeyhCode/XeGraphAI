# relprops.txt — 谓词代数（数据，可审计）
#
# 格式（一行一条，`#` 注释；条目后面可以写行内出处）：
#   prop <谓词> trans        可传递：A R B, B R C ⇒ A R C
#   prop <谓词> sym          对称：A R B ⇔ B R A
#   prop <谓词> inherit      可沿「属于」继承
#   prop <谓词> inv <逆谓词>   A R B ⇒ B inv A（写一遍，两个方向都成立）
#   syn  <谓词> <谓词>        谓词同义 ⇒ 代数同（只走一跳）
#
# ⚠ 来源说明（别把这张表当成"蒸馏产物"）：
#   本轮把蒸馏管线跑通了（tools/distill_relprop.py，多教师 × 双跑取交集 + 确定性过滤），
#   但本地小模型（qwen3-0.6b / coder-1.5b / coder-3b）给出的属性**不可靠**：
#   喜欢/了解/像 被判成对称、保护/怕 被判成可传递，连"请反驳这个断言"的自我反驳提示词
#   也跟着错。实测见 docs/generalize.md。=> 本文件**不收录模型产物**，只收两类有出处的条目。
#
#   [代码] = 由 AI_RELS 里已声明的属性推得（不是新知识，只是把它搬到数据层）
#   [常识] = 汉语里恒成立、且本轮判据要用到的 fixture（对称谓词）
prop 包含 trans        # [代码] 包含 = 属于⁻¹（AI_RELS 声明），属于 声明了 trans
prop 认识 sym          # [常识] A 认识 B ⇔ B 认识 A
prop 相同 sym          # [常识] A 相同 B ⇔ B 相同 A
syn 一样 相同          # [常识]「A 一样 B」与「A 相同 B」同义 ⇒ 代数同（举一反三：一条属性覆盖同义组）
