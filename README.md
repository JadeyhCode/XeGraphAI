# XeGraphAI

图原生 AI 实验体：**符号不直接连符号**，而是"文字 → 空符号 → 意义符号"。
本项目由 JainkAI 演进而来，目标是把记忆、学习、元认知、插件都落在同一张图上。

## 设计要点

1. **文字与意思分离**
   - 文字符号（`词:苹果`）正常情况下只连一个**空符号**（`空:…`）；
   - 空符号再连意义符号（`义:水果`）；
   - 一词多义时，同一个文字用不同关系连到不同空符号（`空:水果` / `空:公司`）。
2. **切碎以增强泛化**
   - "做一个游戏需要窗口库" 被切成 `做游戏 → 需要显示画面 → 需要窗口库` 的多跳链，
     而不是一条长事实。
3. **图补丁（graph patch）**
   - 不存整图：每次会话只存"相对初始图的修改"（新增/删除的边与孤点），
     启动时 初始图 + 补丁 合成。
4. **自由图符号作为按会话隔离的记忆**
   - 每个会话一个 `自由图:<session>` 符号，挂自己的边；会话之间互不可见。
5. **插件**
   - 插件注册自己的符号，并带**自己的联想规则**（`联想:插件` 边）与**行为**（`行为:…`），
     主程序匹配到插件符号时调用对应行为。
6. **搜索与现场学习**
   - `::web` 抓网页、`::learn` 现场学一门语言/专业：抽取词与关系写进补丁，不写死规则。
7. **元认知承接奖励**
   - 奖励不由硬编码规则表给，而由元认知层对"预测误差 / 一致性 / 新颖度"打分回传，
     用于泛化时的取舍。

## 构建

```sh
sh code/build_code_model.sh     # 生成代码知识模型
gcc -std=c11 -O2 -o build_xe main.c -lm
sh tests/all.sh                 # 全量回归
```
